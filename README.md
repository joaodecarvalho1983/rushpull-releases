# RushPull releases

Signed release builds of [RushPull](https://rushpull.com), the Mac app that downloads very large Google Drive folders reliably to any drive.

This repository holds only the release files (the disk image, the signed update files) and their release notes. It contains no source code.

**Download RushPull from [rushpull.com](https://rushpull.com).** RushPull checks for updates by itself and installs them from here, never during a download.

Every build is signed with MaJo Industries' Apple Developer ID, notarized by Apple, and its update files are signed with RushPull's own update key.
